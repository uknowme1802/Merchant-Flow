# MerchantFlow Dashboard

A full-stack payment analytics dashboard with role-based access control.

## Tech Stack

- Frontend: React + Tailwind
- Backend: Node.js + Express
- Database: MongoDB
- Auth: JWT

## Features

- Admin/User login
- Transaction management
- Dashboard analytics
- User management (Admin only)
- CSV export

## Setup

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm run dev
